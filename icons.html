Pacera icon system

One stroke family for the whole finance suite. Drawn on a 16px grid with a 1px stroke so it stays crisp in dense tables, in toolbars and in the 48px main menu. Used the same way in every application.

Each application has a 24px function icon in the 48px header slot. Colour comes from the application: blue for FP&A, Consolidation, Close and Lease, purple for Launchpad, turquoise for ORA. Each icon also exists as a 16px glyph for tables and tabs.

Every icon sits inside the same live area. Keylines keep circles, squares and rectangles visually equal in weight.

Canvas

16 x 16 px. Live area 14 x 14 with 1px padding. Strokes sit on half pixels so they render as sharp 1px lines.

Keylines

Circle 12 px. Square 12 x 12. Portrait rectangle 10 x 13. Landscape rectangle 13 x 10. Use them to size the base shape of an icon.

Stroke

1px, round caps and joins. Stroke never scales, so the 24px menu version keeps the same hairline weight. Filled dots are allowed only as 1.8px accents.

Corners

Outer radius 1.5px on rectangles. Inner details use square joins. No more than one radius per icon.

Badge system

A base icon plus a small badge describes state or action. One badge per icon, always in the lower right.

The same icon changes role with its container. Every example below is rendered with live components.

How the library is shared across the suite. Core icons appear in every application; domain icons belong to a function.

Grid and stroke

16 x 16 canvas, 1px stroke, round caps and joins. A 24px version is the same drawing at 1.5x with the same 1px line.

Colour

Icons use currentColor and inherit text colour. Use blue, turquoise or purple only to show where data comes from.

Naming

Lowercase, hyphenated, noun first: lease-liability, doc-check. Badge variants end with the badge: -plus, -check, -warn.

Accessibility

Decorative icons are hidden from screen readers. An icon-only button needs a text label and a 32px minimum target. Never use colour alone for meaning.

Do

  • Pair an icon with a text label in menus and primary actions.
  • Use the same icon for the same concept in every app.
  • Use the 24px size only in the main menu and app tiles.

Do not

  • Change stroke weight to add emphasis. Change colour or size instead.
  • Combine two badges on one icon.
  • Use a function icon from another app to mean something new.
